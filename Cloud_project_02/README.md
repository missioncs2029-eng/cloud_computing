# Link Terminal — AWS Learner Lab Deployment

This package is a static HTML/CSS/JavaScript frontend configured to use the existing AWS HTTP API directly. The Cloud Endpoint button, configuration modal, and browser Demo Mode have been removed from this deployment build. The API URL is preconfigured in `app.js`.

## Files to upload

Upload these three files together into the root of your static website hosting location:

- `index.html`
- `styles.css`
- `app.js`

## Existing AWS backend

- Region: `us-east-1` (N. Virginia)
- API Gateway HTTP API: `LinkTerminalHTTPAPI`
- Invoke URL: `https://u3ykuix7nf.execute-api.us-east-1.amazonaws.com`
- Save route: `POST /api/links`
- Resolve route: `GET /api/resolve/{short_code}`
- Lambda: `LinkTerminalAPI`
- DynamoDB table: `LinkMappings` (partition key `short_code`, String)

The frontend sends `{ "short_code": "AWS2026", "url": "https://www.wikipedia.org" }` to the save route. Resolve accepts either `url` or `destination_url` in the API response.

## Deploy frontend to S3

1. Start AWS Learner Lab and open AWS Console in `us-east-1`.
2. Open S3 and create a globally unique bucket name.
3. Enable static website hosting with `index.html` as the index document, if the Learner Lab policy allows it.
4. Upload `index.html`, `styles.css`, and `app.js` into the bucket root using these exact filenames.
5. Use the website endpoint generated by S3 to open the page. The header should show `AWS LIVE API MODE`.
6. Resolve `AWS2026` (expected URL: `https://www.wikipedia.org`).
7. Add a new unique short code and destination URL. After a successful save, confirm the new item in DynamoDB table `LinkMappings`.

## CORS is required

The API Gateway HTTP API must allow the origin of the deployed frontend. For temporary testing, `*` is acceptable if the requests do not use credentials. For a restricted configuration, add the exact S3 website origin and allow methods `GET`, `POST`, `OPTIONS` and header `content-type`. Save the CORS configuration; the existing `$default` stage was configured for auto-deploy.

## Validation and limits

- `app.js` passed `node --check` (JavaScript syntax check).
- The ZIP archive is checked for integrity.
- The actual AWS-hosted website cannot be verified from this package alone. Final success depends on Learner Lab permissions, S3 hosting setup, API Gateway CORS, and the API/backend remaining available.
- This package does not create AWS resources automatically.
- Do not delete the API Gateway API, Lambda function, or DynamoDB table if you want to keep using the existing backend.
